# StudyDash 操作指南

> 学习管理台总站：功能卡片门户整合番茄钟、任务管理、计划拆解、学习统计与高数复习，支持多账号（数据互相隔离）。
> 本文档覆盖：本地使用 → 核心功能操作 → 部署到云端服务器 → 数据库配置与备份。

## 1. 本地使用（一分钟上手）

**前提**：Windows 电脑，已安装 Python 3.11+ 和 Node.js（首次运行需要联网装依赖）。

1. 双击项目根目录的 `start.bat`。
2. 脚本会自动安装后端依赖、构建前端、启动服务，并打开浏览器。
3. 浏览器打开 `http://127.0.0.1:8000`，点击「注册」：
   - 用户名：3–50 位字母 / 数字 / 下划线
   - 密码：至少 6 位
   - 邀请码：本地默认 `studydash`（可用环境变量 `INVITE_CODE` 修改）
4. 停止服务：直接关闭弹出的命令行窗口即可。

> 开发调试：在 `frontend` 目录执行 `npm.cmd run dev` 后访问 `http://localhost:5173`（热更新）；改完前端执行 `npm.cmd run build`，`http://127.0.0.1:8000` 会自动用上最新页面。

## 2. 核心功能操作

| 页面 | 做什么 | 怎么用 |
| --- | --- | --- |
| 首页 | 总站门户 | 顶部今日概览；「功能中心」卡片直达各模块；「预留功能区」预置雅思 / 冲刺 / 报告等扩展位 |
| 专注 | 番茄钟 | 时长档位可自定义（默认 25/45/60 分钟）→ 开始/暂停/重置；倒计时结束可关联任务记录本次专注 |
| 任务 | 增删改任务 | 添加任务（标题/科目/预计分钟/所属计划）、筛选状态、标记完成、删除；勾选「设为习惯」后按频率打卡并累计连续天数 |
| 计划 | 大计划拆小计划 | 建根计划 → 「+子计划」逐层拆；节点「拆解」可选内置模板或 AI 生成子计划 |
| 计划-流程图 | 查看整体结构 | 纵向树 / 横向树 / 径向图三种布局；可拖动节点、改大小与颜色、换主题；支持导出 SVG / PNG |
| 文件 | 学习资料上传与整合 | 上传 PDF / Office / Markdown / 图片（分类 + 描述），按账号隔离；管理员可扫描查毒、放行 / 隔离、标记整合 |
| 复习 | 艾宾浩斯复习 | 任务/计划完成后按复习间隔（默认 1/2/4/7/15/30 天，可自定义）生成复习节点；「复习完成」打卡，逾期标红 |
| 统计 | 学习数据 | 今日概览 + 连续专注 streak + 近 105 天专注热力图 + 近 7/14/30 天趋势图（ECharts） |
| 高数 | 高数复习 | 高等数学（上）108 个考点：章节目录 / 搜索 / 标签筛选（必考 / 必背 / 高频 / 证明题 / 定义题 / 应用题 / 易错）/ 掌握标记 / 章节笔记，公式用 KaTeX 渲染 |
| 设置 | 个性化与备份 | 账号信息；🎨 个性化（外观 / 番茄时长 / 复习间隔 / 习惯频率 / 任务默认值 / 首页卡片 / 计划模板）；导出 / 导入数据备份（JSON）；云端部署端口说明 |

> 顶栏右侧有 **🌙 / ☀️ 主题切换** 按钮，深色 / 浅色一键切换，选择会记住，下次打开自动恢复。

**计划拆解三种方式**（在计划节点点「拆解」）：

- **手动**：点「+子计划」逐层创建，层级不限。
- **模板**：学习 / 项目 / 备考 三套内置模板，一键生成 4–6 个子计划。
- **AI**：调用 OpenAI 兼容接口自动拆解。在顶栏「AI」页面配置服务商 / 接口地址 / 模型 / API Key（Key 加密存储、掩码显示），可先「测试连接」再保存；每个账号独立配置。未配置时 AI 入口会提示去设置，不影响模板拆解。


**AI 服务接入**（顶栏「AI」页面）：

- 选择服务商：OpenAI / DeepSeek / 通义千问 / 智谱 GLM / Kimi / 自定义，点击卡片自动填充接口地址与默认模型。
- 填写「接口地址 + 模型 + API Key」，点「测试连接」验证（显示模型回复与耗时），成功后再「保存配置」。
- API Key 在服务器加密存储，页面只显示掩码（如 `sk-********-123`），修改配置时留空则保留原 Key。
- 之后到「计划」页点某计划的「拆解 → AI」，就会用你配置的服务自动生成子计划。

**习惯打卡**（任务页）：

- 添加任务时勾选「🔁 设为习惯」，该任务每天以「打卡」为准，不进入永久已完成状态。
- 每天点「✅ 打卡」完成一次；点「已打卡 ✓ 撤销」可撤销今天的打卡。
- 打卡后习惯卡片显示 🔥 连续天数；首页「今日打卡」汇总当天完成情况。

**复习提醒**（复习页）：

- 普通任务或计划标记为「已完成」时，系统自动按艾宾浩斯间隔（1/2/4/7/15/30 天）生成 6 个复习节点。
- 复习页「待复习」列出今天到期与逾期的项目（逾期标红）；「未来 30 天」提前预览。
- 点「复习完成」记录一次复习；「一键完成到期」批量处理。
- 习惯任务不生成复习节点；复习只在你「此刻完成」任务/计划时生成，不回溯历史数据。

**个性化设置**（设置页「🎨 个性化」分区，按账号保存、换设备同步）：

- **外观**：主题三档（浅色 / 深色 / 跟随系统）+ 5 色强调色（靛蓝 / 绿 / 玫红 / 琥珀 / 紫罗兰），选择后全站即时生效，顶栏 ☀️/🌙 按钮仍可临时切换浅深色。
- **番茄钟时长**：增删 1–5 档时长（1–180 分钟），并指定默认档；专注页按钮与默认选中随设置变化。
- **复习间隔**：增删 1–8 个间隔（1–365 天，保存时自动排序去重）；此后新完成的复习节点按新间隔生成，历史节点不受影响。
- **任务默认值**：习惯默认频率（每天 / 工作日 / 自定义星期）、新建任务默认预计分钟、科目库（任务表单的快捷下拉）。
- **首页功能卡片**：7 张功能卡片（高数 / 番茄 / 任务 / 计划 / 复习 / 统计 / AI）可隐藏，并支持上移 / 下移排序（设置卡片固定展示）。
- **我的计划模板**：自建拆解模板（名称 + 1–20 个子项），计划页「拆解」弹层会优先展示「我的模板」。

习惯频率说明：选「工作日」时周末打卡会被拒绝；选「自定义星期」后只有勾选的星期能打卡，连续天数按「应打卡日均已打卡」计算。全部恢复默认只需不配置对应项即可。

**学习文件**（顶栏「文件」，或首页功能中心卡片）：

- **上传**：选文件 → 填分类（如 数学 / 试卷 / 笔记）与描述 → 上传。白名单扩展名：pdf / doc(x) / ppt(x) / xls(x) / csv / md / txt / png / jpg / jpeg / gif / webp；默认上限 20MB（`MAX_UPLOAD_MB`）。上传时校验文件头，改后缀的脚本会被拒绝。
- **隔离与查毒**：文件先进入「待扫描」队列；配置 `SCAN_COMMAND`（如 `clamscan --no-summary`）后自动扫描，命中病毒自动移入隔离区，本人也无法下载；未配置时保持「待扫描」，不影响本人上传下载。
- **运营整合**：管理员（`ADMIN_USERNAMES`，默认 `admin`）可查看全部用户文件，执行「重新扫描 / 放行 / 隔离 / 拒绝 / 标记整合」，并写运营备注。
- **文件位置**：磁盘上按用户分目录存于 `backend/uploads/files/{user_id}/`，隔离文件在 `backend/uploads/quarantine/`；不通过 URL 直连，下载走鉴权接口。

**高数复习**（顶栏「高数」，或首页功能中心卡片）：

- 进入后看到总进度条、搜索框、标签筛选和章节目录；内容为「高等数学（上）期末复习提纲」的 7 章 / 108 个知识点。
- 点知识点前的勾选框标记「已掌握」，顶部与章节进度条实时更新；再点一次取消。
- 搜索支持关键字（如「极限」「夹逼」「等价无穷小」），也支持按标签只看「必考」「证明题」等。
- 每个章节右上角 📝 打开笔记编辑，保存后显示在章节标题下（支持换行）。
- 「清除进度」一键清空当前账号的全部掌握标记（不影响笔记）。
- 进度与笔记按账号保存、互相隔离；KaTeX 公式渲染与 CSS 随前端一起打包，本地 / 云端部署都不需要联网加载公式库。

**数据备份**（顶栏 ⚙️ 设置页）：

- **导出**：点「⬇️ 导出备份」下载 `studydash-backup-日期.json`，包含任务、计划、专注记录、习惯打卡、复习节点、个性化设置、计划模板、AI 配置（不含 Key）、高数进度与笔记。
- **导入**：点「⬆️ 导入备份」选择 JSON 文件，确认后【覆盖】当前账号全部数据（建议先导出再导入）。
- API Key 加密存储、不随备份导出，恢复后到「AI 设置」重新填写；备份文件可在任意设备 / 新账号恢复，云端 PostgreSQL 同样支持。
- 学习文件（二进制）不包含在 JSON 备份里：迁移设备 / 服务器时直接复制 `backend/uploads/` 目录即可。

**云端端口（已预留）**：

- 后端统一入口 `backend/run.py`：读环境变量 `PORT`（默认 8000）与 `HOST`（云端默认 0.0.0.0）。
- Render：`render.yaml` 用 `python run.py`，平台自动注入 `PORT`；`DATABASE_URL` 填 Render PostgreSQL。
- Docker：根目录 `Dockerfile`，`docker run -p 8000:8000` 即可启动完整应用。
- 单服务器：`deploy/deploy.sh` 已内置（Nginx + systemd，内网 8000）。

## 3. 部署到云端服务器

### 方案 A：阿里云单服务器（推荐，B/S 结构）

一台 Ubuntu 服务器跑完整应用：Nginx 托管前端页面，FastAPI 提供接口（systemd 守护），数据存服务器上的 SQLite。浏览器访问 `http://服务器IP` 就是完整应用。

**第 1 步 买服务器**
1. 阿里云控制台搜索「轻量应用服务器」（或 ECS）。
2. 镜像选 **Ubuntu 22.04 或 24.04**，配置 2 核 2G 起步即可。
3. 购买后记下**公网 IP**。

**第 2 步 防火墙放行端口（最容易踩坑）**
- 轻量服务器：控制台 → 你的服务器 → **防火墙** → 添加规则，放行 **80（HTTP）** 和 **443（HTTPS）**。
- ECS：控制台 → 实例 → **安全组** → 入方向规则，放行 80 / 443。
- 不放行 80，浏览器会一直「无法访问」。

**第 3 步 上传项目**
在本地 `E:\agent专用` 目录打包（已自动排除体积大的目录和数据库文件）：

```powershell
cd E:\agent专用
tar -a -c -f study-dashboard.zip --exclude=study-dashboard/backend/.venv --exclude=study-dashboard/backend/__pycache__ --exclude=study-dashboard/backend/tests/__pycache__ --exclude=study-dashboard/frontend/node_modules --exclude=study-dashboard/frontend/dist --exclude=study-dashboard/backend/study.db study-dashboard
```

上传到服务器并解压到 `/opt/studydash`：

```bash
# 本地 PowerShell 上传（或用控制台 Workbench 的「文件上传」按钮）
scp E:\agent专用\study-dashboard.zip root@服务器公网IP:/tmp/

# 服务器上执行
apt-get install -y unzip
mkdir -p /tmp/pj /opt/studydash
unzip /tmp/study-dashboard.zip -d /tmp/pj
cp -r /tmp/pj/study-dashboard/* /opt/studydash/
```

**第 4 步 一键部署**

```bash
sudo bash /opt/studydash/deploy/deploy.sh
```

脚本会自动：安装 Nginx / Python / Node → 装后端依赖 → 构建前端 → 生成 `SECRET_KEY` 和邀请码 → 安装 systemd 服务 → 配置 Nginx 并启动。**最后会打印邀请码（务必保存）**。

**第 5 步 访问与常用命令**

- 浏览器打开 `http://服务器公网IP`，用打印的邀请码注册即可使用。
- 常用命令：
  ```bash
  systemctl status studydash        # 查看服务状态
  journalctl -u studydash -f        # 实时查看日志
  systemctl restart studydash       # 重启服务
  ```

### 方案 B：Netlify + Render（免运维，可选）

不想自己管服务器时：前端放 Netlify，后端放 Render，数据库用 Render 免费 PostgreSQL。

1. 把项目推到 GitHub。
2. Render 后台创建 **PostgreSQL**，复制 **Internal Database URL**。
3. Render 创建 Web Service（用仓库里的 `render.yaml`），环境变量配置：
   - `DATABASE_URL`：上一步的数据库连接串（**数据库就用这个，见第 4 节**）
   - `SECRET_KEY`：一长串随机字符（JWT 签名用，泄露等于能伪造登录）
   - `INVITE_CODE`：你的注册邀请码
   - `ALLOWED_ORIGINS`：Netlify 站点域名，如 `https://你的站点.netlify.app`
4. Netlify「Add new site → Import an existing project」选同一仓库，构建命令和发布目录由 `frontend/netlify.toml` 自动识别。
5. Netlify 环境变量 `VITE_API_BASE` 填 Render 后端地址，如 `https://studydash-api.onrender.com`。
6. 部署完成后访问 `https://你的站点.netlify.app`。

## 4. 数据库配置

StudyDash 默认用 **SQLite**（一个文件，零配置），读取环境变量 `DATABASE_URL` 后可切换为 **PostgreSQL**。

| 部署方式 | 数据库 | 位置 | 说明 |
| --- | --- | --- | --- |
| 本地 | SQLite | `backend\study.db` | 首次启动自动生成，无需配置 |
| 阿里云单服务器 | SQLite | `/opt/studydash/backend/study.db` | 部署脚本自动生成，无需配置 |
| Netlify + Render | PostgreSQL | Render 托管 | 需手动创建库并配置 `DATABASE_URL` |

**PostgreSQL 配置步骤（Render）**：

1. Render 控制台 → New + → **PostgreSQL**，创建后复制 **Internal Database URL**（形如 `postgres://用户名:密码@主机:端口/库名`）。
2. 在 Render 的 Web Service 环境变量里新增 `DATABASE_URL`，粘贴该连接串。
3. 部署（或重启）Web Service，后端启动时会自动建表；数据此后都存在 PostgreSQL 里，重启/重新部署不丢数据。

> 本地开发想连 PostgreSQL 也可以：把 `DATABASE_URL` 设成你自己的 PostgreSQL 连接串再启动即可，其余代码不用改。

## 5. 环境变量速查

| 变量 | 必填 | 作用 | 示例 |
| --- | --- | --- | --- |
| `SECRET_KEY` | 是 | JWT 签名密钥，**线上务必改成随机长串** | `openssl rand -hex 32` 生成 |
| `INVITE_CODE` | 是 | 注册邀请码 | `studydash` |
| `DATABASE_URL` | 否 | 切换 PostgreSQL（默认 SQLite） | `postgres://...` |
| `ALLOWED_ORIGINS` | 否 | 允许跨域的前端域名（逗号分隔） | `https://你的站点.netlify.app` |
| `LLM_API_BASE` | 否 | AI 拆解接口基地址（OpenAI 兼容） | `https://api.deepseek.com/v1` |
| `LLM_API_KEY` | 否 | AI 拆解密钥，配置后才启用 AI | `sk-xxxx` |
| `LLM_MODEL` | 否 | AI 拆解模型名 | `deepseek-chat` / `qwen-plus` / `gpt-4o-mini` |
| `ADMIN_USERNAMES` | 否 | 运营管理员用户名（逗号分隔），**线上务必改成自己的账号** | `admin` |
| `MAX_UPLOAD_MB` | 否 | 学习文件上传上限（MB），默认 20 | `20` |
| `SCAN_COMMAND` | 否 | 病毒扫描命令（查毒预留），配置后自动/手动扫描 | `clamscan --no-summary` |
| `UPLOAD_DIR` | 否 | 学习文件存储目录，默认 `backend/uploads` | `/opt/studydash/backend/uploads` |

- **本地**：PowerShell 里用 `$env:变量名 = "值"` 设置后再启动服务（应用不会自动读取 `.env` 文件；服务器上能读是因为 systemd 的 `EnvironmentFile` 加载了 `/opt/studydash/.env`）。
- **阿里云**：编辑 `/opt/studydash/.env`，然后 `systemctl restart studydash`。
- **Render**：在 Web Service 的 Environment 里添加，保存后自动重启。

## 7. 数据备份与恢复

**SQLite（本地 / 阿里云）**——整个数据库就是一个文件，直接拷贝即可：

```bash
# 备份
cp /opt/studydash/backend/study.db /opt/studydash/backend/study.db.bak-$(date +%F)

# 恢复：停服务 → 覆盖文件 → 起服务
systemctl stop studydash
cp /opt/studydash/backend/study.db.bak-xxxx /opt/studydash/backend/study.db
chown studydash:studydash /opt/studydash/backend/study.db
systemctl start studydash
```

学习文件（`backend/uploads/`）一起备份：`cp -r /opt/studydash/backend/uploads /opt/studydash/backend/uploads.bak-$(date +%F)`。

**PostgreSQL（Render）**——直接在 Render 控制台的 PostgreSQL 页面用 Backup / Export 功能导出。

## 8. 常见问题

- **浏览器打不开网站**：多半是防火墙没放行 80 端口（见第 3 节第 2 步）。
- **页面能开但接口报错（后端未启动）**：本地先跑自检 `backend\.venv\Scripts\python.exe scripts\selfcheck.py`（检查依赖 / 数据库 / 端口 / 前端产物）；云端 `journalctl -u studydash -f` 看日志，`systemctl status studydash` 看状态。
- **本地双击 start.bat 提示启动失败**：看 `backend\backend.log` 的报错，常见原因是端口被占用（设 `PORT=8123` 再启动）或依赖未装全（先跑自检脚本）。
- **AI 拆解提示「尚未配置 AI 服务」**：登录后到顶栏「AI」页面配置服务商与 API Key（推荐）；或由服务器设置 `LLM_API_KEY` 环境变量作为兜底。不配置也能用模板拆解。
- **番茄钟时长 / 复习间隔不是我要的**：到「设置 → 🎨 个性化」修改对应项；番茄时长至少保留 1 档、默认值必须在列表内，复习间隔 1–8 项会自动排序去重。
- **主题没按我设置的样子显示**：确认已登录（设置按账号保存）；未登录时顶栏按钮只改本浏览器记忆；在「个性化 → 外观」选「浅色 / 深色」可强制固定，选「跟随系统」则随操作系统变化。
- **顶栏显示「后端未启动」**：双击 `start.bat`（或 `启动后端.bat`）启动后端；顶栏圆点每 15 秒自动检测，也可点击立即重检。
- **上传文件被拒**：确认扩展名在白名单内、文件头与扩展名一致、大小未超 `MAX_UPLOAD_MB`（云端还要看 Nginx 的 `client_max_body_size`，已默认放 25m）。
- **本地旧版本升级**：运行迁移脚本补字段 `backend\.venv\Scripts\python.exe scripts\migrate_local.py --username admin --password 你的密码`，或直接删 `backend\study.db` 重新开始。
- **忘记登录密码**：本地/阿里云可删除 `users` 表里对应用户后重新注册（数据不删），或用迁移脚本重建引导账号。
