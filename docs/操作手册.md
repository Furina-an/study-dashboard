## 1. 这是什么

**StudyDash** 是一套「学习管理台」网页应用（B/S 结构，浏览器访问即用），单项目整合：

- 🍅 番茄钟专注（自定义时长，完成可关联任务）
- ✅ 任务管理（增删改、科目、预计分钟、所属计划、完成状态）
- 🔁 习惯打卡（任务标记为习惯，每日打卡 + 连续天数）
- 🗂️ 计划拆解（大计划无限层级拆小计划：手动 / 模板 / AI 三种方式）
- 🧭 计划流程图（树状 / 横向 / 径向，可拖动改样式，导出 SVG / PNG）
- 📚 学习文件（上传 PDF / Office / 图片，按账号隔离，管理员查毒 / 整合）
- 🧠 复习提醒（任务 / 计划完成后自动生成艾宾浩斯 1/2/4/7/15/30 天复习节点）
- 📊 学习统计（今日概览、连续专注、105 天热力图、7/14/30 天趋势）
- 🧮 高数复习（高等数学上 108 考点：搜索 / 标签筛选 / 掌握标记 / 章节笔记，公式 KaTeX 渲染）
- 🤖 AI 拆解接入（OpenAI 兼容：DeepSeek / 通义 / 智谱 / Kimi / 自定义）
- 🛡️ 管理后台（邀请码生成器控制注册人数、用户列表）

**技术架构**

| 层 | 技术 |
| --- | --- |
| 前端 | Vue 3 + Vite + Vue Router + Pinia + ECharts |
| 后端 | FastAPI + SQLAlchemy |
| 数据库 | 本地/单服务器默认 SQLite，云端可切换 PostgreSQL |
| 认证 | 邀请码注册 + JWT 登录（7 天有效），每账号数据互相隔离 |

## 2. 本地安装与启动

**前提**：Windows 电脑，已安装 Python 3.11+ 与 Node.js 20+（首次运行需要联网下载依赖）。

### 方式一：一键启动（推荐）

1. 双击项目根目录 `start.bat`。
2. 脚本自动：装后端依赖 → 装前端依赖 → 构建前端 → 启动后端 → 打开浏览器。
3. 浏览器访问 http://127.0.0.1:8000

### 方式二：手动启动（开发调试）

```powershell
# 终端 1：后端（端口 8000）
cd backend
.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

# 终端 2：前端（端口 5173，热更新）
cd frontend
npm.cmd run dev
```

开发时访问 http://localhost:5173，Vite 会把 `/api` 请求代理到后端 8000。

### 停止服务

- `start.bat` 启动的：直接关闭弹出的命令行窗口。
- 手动启动的：在对应终端按 `Ctrl+C`。

## 3. 账号与邀请码（含管理后台）

### 3.1 注册

「注册」页填写：

| 字段 | 规则 |
| --- | --- |
| 用户名 | 3–50 位字母 / 数字 / 下划线，唯一 |
| 密码 | 至少 6 位 |
| 邀请码 | 主邀请码（本地默认 `studydash`）或管理员发放的邀请码 |

### 3.2 主邀请码与数据库邀请码

- **主邀请码**（环境变量 `INVITE_CODE`）：永远可用、不计数，用于管理员自己注册或应急。
- **数据库邀请码**（管理后台生成）：必须满足「启用 + 未过期 + 未用完」才能注册成功，注册成功即扣减一次，用完自动失效。

### 3.3 谁是管理员

管理员由环境变量 `ADMIN_USERNAMES` 指定（逗号分隔，默认 `admin`）。**只要用户名匹配即视为管理员**，因此：

1. 注册一个叫 `admin` 的账号（用主邀请码）。
2. 用该账号登录，导航栏会出现「🛡️ 管理」入口。

> ⚠️ 线上部署务必把 `ADMIN_USERNAMES` 改成你的专属运营账号，避免别人注册同名账号成为管理员。

### 3.4 管理后台操作

| 功能 | 操作 |
| --- | --- |
| 查看概览 | 打开「管理」页，顶部卡片显示：注册用户数 / 有效邀请码 / 未使用邀请码 / 累计邀请码 |
| 生成邀请码 | 「生成数量」1–50 个；「每个码可用次数」默认 1 次；「有效天数」留空=永久；「备注」如「送给同学第二批」；点「生成邀请码」 |
| 复制邀请码 | 生成后点击单个邀请码复制，或点「复制全部」；发给想邀请的人即可 |
| 停用 / 启用 | 邀请码列表点「停用」（立即失效）或「启用」恢复 |
| 删除邀请码 | 点「删除」并确认（不可恢复） |
| 查看用户 | 「用户」页签显示全部注册用户、角色（管理员/普通用户）、状态（正常/已禁用）、注册时间 |
| 禁用 / 启用用户 | 「用户」页签点「禁用」可封禁该账号（登录被拒、已有登录态立即失效）；点「启用」恢复。不能禁用自己或其他管理员 |
| 文件运营 | 「文件运营」页签查看全部用户上传的学习文件，可按状态筛选；支持下载、放行、拒绝、隔离、重新扫描、标记整合、删除 |

> 后台采用左侧导航（概览 / 邀请码 / 用户 / 文件运营），手机端自动折叠为顶部横排页签。

**控制使用者人数的正确姿势**：每个码限 1 次、发放 N 个，用完即止；需要加人时再生成，随时可以停用某人的码；对违规账号直接在「用户」页签禁用。

## 4. 功能模块操作

### 4.1 首页（Dashboard）

- 顶部：今日专注分钟、专注次数、完成任务数、连续 streak。
- 「功能中心」卡片：直达各模块；卡片的显隐与顺序可在「设置 → 🎨 个性化 → 首页卡片」调整。
- 「预留功能区」：预置雅思 / 冲刺 / 报告等扩展位，供后续功能接入。

### 4.2 专注（番茄钟）

1. 选择时长档位（默认 25 / 45 / 60 分钟，可在设置中增删、改默认）。
2. 开始 / 暂停 / 重置；倒计时结束弹窗可关联任务记录本次专注。
3. 记录会进入统计（今日专注、热力图、趋势）。

### 4.3 任务

- 添加任务：标题（必填）、科目（可从设置维护的科目库选择）、预计分钟、所属计划（可选）。
- 状态流转：todo → doing → done；标记完成可勾选。
- **设为习惯**：勾选后该任务转为每日打卡模式，不进入永久完成；每天「✅ 打卡」/「撤销」，连续天数累计。
- 删除任务：列表操作区点「🗑️」。

### 4.4 计划（大计划 → 小计划）

1. 建根计划：标题 + 描述（可选）。
2. 添加子计划：节点点「+子计划」逐层创建，层级不限。
3. **拆解**（节点「拆解」按钮）：
   - **手动**：逐层创建。
   - **模板**：学习 / 项目 / 备考三套内置模板，一键生成 4–6 个子计划；也可用设置里自建的「我的模板」。
   - **AI**：调用你配置的 AI 服务自动拆解（见 4.9）。
4. 删除计划：子计划级联删除，其下任务自动解除挂接（任务不删除）。
5. **流程图**标签页：纵向树 / 横向树 / 径向图三种布局；节点可拖动、改大小 / 颜色 / 主题；「导出 SVG / PNG」一键下载。

### 4.5 学习文件

- 上传：选择文件（PDF / Word / PPT / Excel / Markdown / 图片，最大 `MAX_UPLOAD_MB`，默认 20MB）+ 分类 + 描述。
- 安全：扩展名白名单 + 文件头魔数校验 + 大小限制；文件按账号隔离，UUID 重命名落盘，不提供直链。
- 状态：待扫描 → 通过（可被管理员「整合」）；管理员可重新扫描、放行 / 隔离 / 拒绝并写备注。
- 下载：自己上传的文件随时可下载；被隔离的文件需管理员放行。

### 4.6 复习（艾宾浩斯）

- 任务 / 计划标记为完成时，自动生成复习节点（间隔默认 1/2/4/7/15/30 天，可在设置中修改）。
- 复习页：今日到期优先（逾期标红），点「复习完成」打卡；「完成所有到期复习」一键处理。
- 历史列表可查已复习记录。

### 4.7 统计

- 今日概览卡片；连续专注天数（streak）。
- 近 105 天专注热力图（ECharts 日历图）。
- 近 7 / 14 / 30 天专注趋势折线 / 柱状图。

### 4.8 高数复习

- 高等数学（上）108 个考点按章节目录展示；顶部搜索框 + 标签筛选（必考 / 必背 / 高频 / 证明题 / 定义题 / 应用题 / 易错）。
- 点考点「✓」标记掌握；章节「📝」写笔记（进度与笔记按账号保存）。
- 公式用 KaTeX 本地渲染，离线可用。

### 4.9 AI 服务（顶栏「AI」）

1. 选择服务商（OpenAI / DeepSeek / 通义千问 / 智谱 / Kimi / 自定义），自动填充接口地址与默认模型。
2. 填写接口地址 + 模型 + API Key，点「测试连接」验证，成功后再「保存配置」。
3. Key 加密存储、只显示掩码；备份文件不包含 Key，换设备后重新填写。
4. 回到「计划」页，对某计划点「拆解 → AI」即可自动生成子计划。
5. 未配置时 AI 入口给出提示，模板拆解不受影响。

### 4.10 设置

- **账号信息**：用户名、创建时间。
- **🎨 个性化**（按账号保存、换设备同步）：
  - 外观：浅色 / 深色 / 跟随系统 + 5 色强调色。
  - 番茄钟时长：增删档位（至少保留 1 档）、设置默认时长。
  - 复习间隔：1–365 天、最多 8 项、自动排序去重。
  - 习惯默认频率：每天 / 工作日 / 自定义星期。
  - 任务默认分钟、科目库（datalist 快捷输入）。
  - 首页卡片：显隐与上移 / 下移排序。
  - 计划模板：自建模板（名称 + 子项列表），拆解时可直接选用。
- **数据备份**：导出全部数据为 JSON / 从 JSON 恢复（见第 5 节）。
- **云端部署**：后端端口说明（`PORT` 环境变量）。

### 4.11 主题切换

顶栏右侧 🌙 / ☀️ 一键切换深 / 浅色；登录后选择会写入账号设置，换设备自动恢复。

## 5. 数据备份与恢复

### 5.1 应用内 JSON 备份（推荐，含全部业务数据）

- **导出**：「设置 → 数据备份 → 导出」，得到 `studydash-backup-*.json`（含任务 / 计划 / 专注 / 打卡 / 复习 / 个性化设置 / 计划模板 / 高数进度与笔记 / AI 配置信息）。
- **导入**：「导入备份」选择 JSON 文件，覆盖当前账号数据。
- 注意：AI 的 API Key 不随备份导出；学习文件（二进制）不包含在 JSON 里，需单独备份 `backend/uploads/` 目录。

### 5.2 数据库文件备份（SQLite）

```bash
# 备份
cp /opt/studydash/backend/study.db /opt/studydash/backend/study.db.bak-$(date +%F)
# 学习文件
cp -r /opt/studydash/backend/uploads /opt/studydash/backend/uploads.bak-$(date +%F)

# 恢复：先停服务，覆盖文件后启动
systemctl stop studydash
cp /opt/studydash/backend/study.db.bak-xxxx /opt/studydash/backend/study.db
chown studydash:studydash /opt/studydash/backend/study.db
systemctl start studydash
```

### 5.3 PostgreSQL（Render）

在 Render 控制台的 PostgreSQL 页面用 **Backup / Export** 功能导出，必要时新建库再导入。

## 7. 部署到云端（上线）

### 方案 A：阿里云单服务器（推荐，B/S 结构）

一台 Ubuntu 服务器跑完整应用：Nginx 托管前端，FastAPI 提供接口（systemd 守护），数据存 SQLite。

**第 1 步 买服务器**：阿里云控制台 → 轻量应用服务器（或 ECS）→ Ubuntu 22.04 / 24.04，2 核 2G 起步，记下公网 IP。

**第 2 步 放行端口（最容易踩坑）**：
- 轻量：控制台 → 防火墙 → 添加规则放行 **80 / 443**。
- ECS：控制台 → 安全组 → 入方向放行 **80 / 443**。

**第 3 步 上传项目**：

```powershell
# 本地打包（已排除 .venv / node_modules / dist / study.db 等）
cd E:\agent专用
tar -a -c -f study-dashboard.zip --exclude=study-dashboard/backend/.venv --exclude=study-dashboard/backend/__pycache__ --exclude=study-dashboard/backend/tests/__pycache__ --exclude=study-dashboard/frontend/node_modules --exclude=study-dashboard/frontend/dist --exclude=study-dashboard/backend/study.db study-dashboard

# 上传（或用阿里云 Workbench 的「文件上传」按钮）
scp E:\agent专用\study-dashboard.zip root@服务器公网IP:/tmp/

# 服务器上解压
apt-get install -y unzip
mkdir -p /tmp/pj /opt/studydash
unzip /tmp/study-dashboard.zip -d /tmp/pj
cp -r /tmp/pj/study-dashboard/* /opt/studydash/
```

**第 4 步 一键部署**：

```bash
sudo bash /opt/studydash/deploy/deploy.sh
```

脚本自动：装 Nginx / Python / Node → 装后端依赖 → 构建前端 → 生成 `SECRET_KEY` 与邀请码 → 装 systemd 服务 → 配 Nginx → 启动。**最后会打印邀请码（务必保存）**。

**第 5 步 访问与运维**：

```bash
systemctl status studydash      # 服务状态
journalctl -u studydash -f      # 实时日志
systemctl restart studydash     # 重启
```

浏览器打开 `http://服务器公网IP`，用打印的邀请码注册。

### 方案 B：Netlify + Render（免运维）

1. 项目已在 GitHub（推荐 public，Render 授权后可直接关联）。
2. Render 后台创建 **PostgreSQL**，复制 **Internal Database URL**。
3. Render 新建 **Web Service**（仓库根目录有 `render.yaml` 会自动识别），环境变量：
   - `DATABASE_URL`：上一步连接串
   - `SECRET_KEY`：一长串随机字符（`openssl rand -hex 32` 生成）
   - `INVITE_CODE`：你的注册邀请码
   - `ADMIN_USERNAMES`：你的运营账号（务必改掉默认的 `admin`）
   - `ALLOWED_ORIGINS`：Netlify 站点域名
4. Netlify：「Add new site → Import an existing project」选同一仓库；`frontend/netlify.toml` 自动配置构建（`npm run build`）与路由回退。
5. Netlify 环境变量 `VITE_API_BASE` 填 Render 后端地址，如 `https://studydash-api.onrender.com`，重新部署。
6. 访问 `https://你的站点.netlify.app` 即可。

### 方案 C：Docker（自托管 / 云主机均可）

```bash
docker build -t studydash .
docker run -d -p 8000:8000 -e SECRET_KEY=xxx -e INVITE_CODE=xxx studydash
```

### 绑定域名 + HTTPS（可选）

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

证书自动续期，之后用 `https://你的域名` 访问。

## 8. 数据库配置

默认 **SQLite**（零配置）；读取环境变量 `DATABASE_URL` 后切换 **PostgreSQL**。

| 部署方式 | 数据库 | 位置 | 说明 |
| --- | --- | --- | --- |
| 本地 | SQLite | `backend\study.db` | 首次启动自动建表 |
| 阿里云 | SQLite | `/opt/studydash/backend/study.db` | 部署脚本自动生成 |
| Netlify + Render | PostgreSQL | Render 托管 | 需创建库并配置 `DATABASE_URL` |

本地想连 PostgreSQL：把 `DATABASE_URL` 设为连接串再启动即可，代码无需改动。

## 9. 环境变量速查

| 变量 | 必填 | 作用 | 示例 |
| --- | --- | --- | --- |
| `SECRET_KEY` | 是 | JWT 签名密钥，**线上务必随机长串** | `openssl rand -hex 32` |
| `INVITE_CODE` | 是 | 主邀请码（永远可用） | `studydash` |
| `DATABASE_URL` | 否 | 切换 PostgreSQL（默认 SQLite） | `postgres://...` |
| `ALLOWED_ORIGINS` | 否 | 允许跨域前端域名（逗号分隔） | `https://你的站点.netlify.app` |
| `LLM_API_BASE` | 否 | AI 拆解接口基地址（OpenAI 兼容） | `https://api.deepseek.com/v1` |
| `LLM_API_KEY` | 否 | AI 拆解密钥 | `sk-xxxx` |
| `LLM_MODEL` | 否 | AI 拆解模型名 | `deepseek-chat` |
| `ADMIN_USERNAMES` | 否 | 管理员用户名（逗号分隔），**线上务必改** | `admin` |
| `MAX_UPLOAD_MB` | 否 | 上传大小上限，默认 20 | `20` |
| `SCAN_COMMAND` | 否 | 病毒扫描命令（查毒预留） | `clamscan --no-summary` |
| `UPLOAD_DIR` | 否 | 学习文件目录 | `/opt/studydash/backend/uploads` |
| `PORT` | 否 | 后端端口（云端注入） | `8000` |

- 本地设置：`$env:变量名 = "值"` 后再启动。
- 阿里云：编辑 `/opt/studydash/.env` 后 `systemctl restart studydash`。
- Render：Web Service 的 Environment 里添加，保存自动重启。

## 10. 常见问题排查

| 现象 | 排查与解决 |
| --- | --- |
| 浏览器打不开网站 | 防火墙未放行 80 / 443（见 7-方案 A 第 2 步） |
| 页面能开、接口报错 | 后端未启动：本地双击 `start.bat`；云端 `journalctl -u studydash -f` |
| start.bat 启动失败 | 看 `backend\backend.log`；端口占用就 `set PORT=8123` 再启动 |
| 顶栏「后端未启动」 | 启动后端后等 15 秒自动重检，或点圆点立即检测 |
| 注册提示邀请码无效 | 确认码未过期、未用完、未停用；主码用 `INVITE_CODE` 的值 |
| 上传文件被拒 | 扩展名是否在白名单、文件头是否匹配（伪装文件会被拒）、是否超 `MAX_UPLOAD_MB` |
| AI 拆解提示未配置 | 到「AI」页配置服务商 + Key；或服务器设 `LLM_API_KEY` 兜底 |
| 番茄时长 / 复习间隔不生效 | 到「设置 → 个性化」修改；登录后设置按账号保存 |
| 主题不对 | 未登录时只改本机记忆；登录后在「个性化 → 外观」选择并保存 |
| 忘记登录密码 | 本地 / 阿里云：删 `users` 表对应用户后重新注册（数据保留），或跑迁移脚本重建引导账号 |
| 旧版本升级 | `backend\.venv\Scripts\python.exe scripts\migrate_local.py --username admin --password 你的密码`，或删 `study.db` 重新开始 |
| 本地自检 | `backend\.venv\Scripts\python.exe scripts\selfcheck.py`（依赖 / 数据库 / 端口 / 前端产物） |
